Services

  • publish: canonical hash, reject duplicates, attribution, queue anchor
  • license: build the transaction; confirm it on devnet hit our program’s PDA
  • challenges: server replays input scripts; board uses the replay score only
  • search + recommend: vector kNN + lineage, reciprocal rank fusion 1/(60+rank)
  • AI router: 1 in flight, 8 per minute, 2,000-char prompts, breaker, JSON repair, key redaction
  • store: MongoStore in live mode, MemoryStore in mock mode

@forklab/engine (pure TypeScript, no React, Next or Solana)

  • schema (zod) · hash: canonical JSON + sha256 (@noble/hashes)
  • attribution: counted nodes only, shares in bps summing to 10,000 · diff
  • world + interpreter: int32 fixed-point, named seeded RNG streams
  • rules · replay · minigame compose · payout flatten · structure vector
  • export: C# mechanic and Unity asset zip (JSZip)
  • Used by the browser, the server and the chain jobs

MongoDB Atlas

  • graphs (_id = graph hash), assets, licenses (unique graphId + buyer), challenges, entries, replays, votes, activity
  • $graphLookup on parentId: ancestors and descendants for lineage and payouts
  • Vector Search: graphs_structure, graphs_semantic (768-d), assets_semantic; brute-force cosine fallback

AI providers, in order

  • Gemini gemini-2.5-flash: generateContent, JSON schema output · gemini-embedding-001, 768-d
  • NVIDIA Nemotron: OpenAI-style chat completions, 45 s timeout
  • Cached answers, then a local non-AI fallback
  • Breaker opens after 3 failures in 60 s

Solana devnet

  • Anchor 0.32 program “forklab” (Rust)
  • initialize: Config PDA, 5% fee
  • register_mechanic: graph hash + author bps
  • license: fee, then each author; dust to first
  • create_challenge (escrow) · settle (snapshot hash, payout bps) · refund after grace
  • Memo program: {app, kind, graph, prev} hash chain

Unity

Downloaded zip: C# mechanic whose header holds the graph hash and authors; prefabs and themes as ScriptableObjects, JSON and an importer script.

Chain worker

anchor-worker.ts

  • Paid mechanic: register_mechanic + Memo in one transaction
  • Free graph: Memo only
  • One at a time, 1.2 s gap, backoff to 60 s on 429; airdrop top-up

Weekly settle

settle-weekly.ts, hourly systemd timer

  • Ended game: flatten payout from the snapshot
  • Send settle + Memo with the same hash
  • Open next ISO week’s game; idempotent

Weekly bot

post-weekly.ts

  • Read the most-forked mechanic from MongoDB
  • Grok writes a one-line blurb
  • Post to X with the Blink URL; --dry-run to Discord

1Build with AI: editor → /api/ai/graph → AI router → Gemini (or Nemotron) → zod check, one repair retry → proposal shown → user presses Apply
2Publish: /api/mechanics → engine hashes canonical JSON and computes author bps → Mongo graphs → chain worker → Memo (and register_mechanic if paid) on devnet
3Discover: /api/search → Gemini embedding → Atlas $vectorSearch (semantic + structure) + $graphLookup kin → rank fusion → results
4License: app or Blink builds the transaction → wallet signs → Anchor license pays fee + every author atomically → server confirms → licenses
5Verify: browser re-hashes the stored graph → RPC getTransaction → base58-decode the Memo → compare hash and parent
6Weekly game: play in browser → input script + signMessage → server replays with the engine → replays → weekly settle pays players and authors
7Export: /api/mechanics/[hash]/export → engine writes C# and asset files → JSZip → import into Unity
·Fallbacks: Mongo down → memory (dev) or fail fast (live) · vector search down → brute force · Gemini down → Nemotron → cache → local · RPC 429 → backoff
